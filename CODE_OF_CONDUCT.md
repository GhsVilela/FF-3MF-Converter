# Code of Conduct

## Our pledge

We want FF-3MF Converter to be a welcoming project for everyone, regardless of
experience, background, identity or preferred slicer.

## Expected behaviour

- Be respectful and constructive.
- Assume good intent and ask clarifying questions.
- Give actionable feedback about code and behaviour, not about people.
- Respect printer and slicer trademarks and do not share proprietary assets.
- Do not post other people's models, personal data or credentials.

## Unacceptable behaviour

Harassment, discrimination, threats, personal attacks, doxxing, sexualised
content, spam and deliberate disruption are not acceptable.

## Scope

This applies to issues, pull requests, discussions, reviews and any project
space.

## Enforcement

Maintainers may remove content, close threads or block participation when
behaviour violates this code. Reports can be sent privately to the repository
owner through GitHub.

## Attribution

This is a short project-specific code of conduct. It is informed by the
Contributor Covenant, version 2.1.
